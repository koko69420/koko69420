### ⚡ About Me

I am an **Electronics and Communication Engineering** undergraduate (B.Tech, Class of 2027) specializing in **embedded firmware, custom hardware engineering, and high-frequency RF systems**.

My work centers on building hard-wired, deterministic, and power-efficient physical systems—from in-wall multi-channel RISC-V nodes running custom RS-422 protocols to planar CubeSat microwave filters and self-hosted high-availability storage arrays. Outside of hardware labs and firmware debuggers, I am an avid portrait, event, and street photographer.

- 🔭 **Current Focus**: Designing multi-channel smart electrical nodes and dual-transceiver room segmentation gateways for the [HomeBus](https://github.com/koko69420/HomeBus) distributed automation network.
- 📡 **RF & Microwaves**: Synthesizing planar microstrip bandpass filters with Defected Ground Structures (DGS) for sub-GHz satellite links in [Microstrip_DGS](https://github.com/koko69420/Microstrip_DGS).
- 🖥️ **Systems & Infrastructure**: Managing [AVK-Vault](https://github.com/koko69420/AVK-Vault-NAS), an 8.2 TiB hybrid storage server running Debian 13, MergerFS JBOD union pooling, daily SnapRAID parity with automated delete guards, and NVMe write caching.
- 📐 **Digital Design**: Implementing RISC-V core processors and digital synthesis flows in [Samsung-RISCV](https://github.com/koko69420/Samsung-RISCV).
- 📷 **Creative Pursuit**: Portrait, event, and documentary street photography.

| **[Microstrip_DGS](https://github.com/koko69420/Microstrip_DGS)** | RF & Microwave Filter Toolchain | Specialized MATLAB analytical synthesis, Chebyshev polynomial filter design, and electromagnetic modeling toolchain for an 868 MHz CubeSat planar microstrip bandpass filter using dumbbell Defected Ground Structures (DGS). |
| **[AVK-Vault NAS](https://github.com/koko69420/AVK-Vault-NAS)** | DIY Storage Server & Cloud Replacement | Architectural blueprint and operational playbook for a low-power 8.2 TiB home server running Debian 13, MergerFS JBOD union pooling, daily SnapRAID parity with automated delete guards, NVMe write cache, and Docker container stacks. |
| **[Samsung-RISCV](https://github.com/koko69420/Samsung-RISCV)** | Digital VLSI & Processor Architecture | Design, functional simulation, logic synthesis, and physical implementation flow for a 32-bit RISC-V processor core. |
| **[VNA-Filter-Analyzer](https://github.com/koko69420/VNA-Filter-Analyzer)** | RF Instrumentation & S-Parameter Analytics | Desktop instrumentation suite for Vector Network Analyzers, automating Touchstone (.s2p)/CST/RVITM S-parameter parsing, Chebyshev -3 dB crossing interpolation, and DGS comparative characterization. |
