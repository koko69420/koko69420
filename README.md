## 🚀 Featured Projects

- **[HomeBus](https://github.com/koko69420/HomeBus)**  
  Distributed, hard-wired home automation platform using full-duplex RS-422, 24V centralized power distribution, WCH CH32X RISC-V nodes, and Home Assistant integration.

- **[Microstrip_DGS](https://github.com/koko69420/Microstrip_DGS)**  
  Specialized MATLAB design, Chebyshev analytical synthesis, and electromagnetic modeling toolchain for an 868 MHz CubeSat microstrip bandpass filter with Defected Ground Structure.
